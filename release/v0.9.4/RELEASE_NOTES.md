# VIP Sim v0.9.4 — 发布说明

发布日期：2026-06-19

## 本版本交付内容

- **扩展安装包** `vip-sim-0.9.4.vsix`：内置完整仿真工具包（Python 工具链 + AXI-Stream
  BFM + Makefile + passthrough 示例 IP），通过「新建仿真项目」复制进用户项目。
- **仿真控制台**：选 IP / 分辨率 / 帧数、寄存器编辑、导入图像、生成图卡、一键仿真、
  导出图像、6 维度质量分析（对比 / 差异 / 锐度 / 白平衡 / 直方图 / PSNR）、IDE 内查看波形。
- **金标准比对**：Python 参考模型按位复现 RTL 定点运算，运行后显示 PASS/FAIL。
- **用户手册**：`VIP仿真平台用户说明书.pdf`、`awesom_VIP开发课题说明书.pdf`。

> 各历史版本（0.9.3 / 0.9.2）的安装包归档于 `release/v0.9.3/`、`release/v0.9.2/`。
