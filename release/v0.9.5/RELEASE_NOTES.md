# VIP Sim v0.9.5 — 发布说明

发布日期：2026-06-21

## 交付内容

- **扩展安装包** `vip-sim-0.9.5.vsix`：内置完整仿真工具包（Python 工具链 + AXI-Stream
  BFM + Makefile + passthrough 示例 IP）。
- **用户说明书** `VIP仿真平台用户说明书.pdf`（已随本版更新）。
- **开发课题说明书** `awesom_VIP开发课题说明书.pdf`。

## 本版新增 / 改进（相对 0.9.4）

- **寄存器读写自检**：`reg_config` BFM 由「只写」升级为「写 → 逐个回读比对 → 放行视频流」。
  视频流启动前用逻辑实跑寄存器读/写时序，打印 `REGCHK PASS/FAIL`（失配给出 `@addr/写/读`
  明细），确认 IP 寄存器接口正确后才喂像素，而非"表单写下去就算配置成功"。
- **平台改进 #1**：按 `regdef.json` 的 `default` 生成默认 regcfg（替代清空），帧间类 IP
  不再因空配置挂死。
- **平台改进 #2 / #3**：新增 `rtl/<ip>/ip.json` 清单（维度变换 + IP 分类）；verify 按输入
  维度建模 / 输出维度比对；analyze 按分类门控逐像素对齐指标（几何/帧间类不再误用 PSNR）。
- **平台改进 #4**：金标准随 IP 自动发现（扫描 `rtl/*/golden.py`），新 IP 自包含，无需改公共文件。
- **平台改进 #5**：可插读地址帧缓冲 `axi_frame_buffer_addr.v` + 容量自适配，支持转置等几何变换 IP。
- **控制台「查看波形」按钮**：改用醒目的青绿强调样式，工具栏更易找到。

> 以上改进全部向后兼容，现有 IP 零回归。
> **升级老项目**：在项目内运行 `VIP Sim: 同步环境文件到当前项目`，把新 BFM / 脚本 / 规则
> 同步过去；若旧 TB 未把 DUT 的 `cfg_rdata` 接回 `reg_config`，补上该连接即可启用寄存器自检。
